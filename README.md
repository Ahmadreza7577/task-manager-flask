# TaskFlow — Task Manager

TaskFlow is a simple task management web application built with Python and Flask.

## Features

- Add, edit, and delete tasks
- Mark tasks as completed
- Set task priorities and due dates
- Add task descriptions
- Search tasks by title or description
- Filter tasks by status and due date
- Sort tasks by creation date, priority, or due date
- View overdue, due today, and upcoming task badges
- Track task completion with a progress bar
- Store tasks in a local SQLite database

## Requirements

- Python 3.10 or newer
- pip
